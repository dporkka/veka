# Veka 0.9 — first-sight learning for English, Mandarin and Brazilian Portuguese

**Status:** pedagogical tooling for frozen canonical Veka, not a language reform.
Translations below are manually curated, not generated by a translation engine.
No comprehension, pronunciation, retention or learning-time results have been
collected. The teaching aids are not validation of fluency or lexical superiority.

## Run

Requires Python 3.10+; no extra Python packages.

```sh
python3 -m veka lessons --lang en
python3 -m veka lessons --lang zh
python3 -m veka lessons --lang pt-BR
python3 -m veka lessons --lang zh --format json
python3 -m veka beginner 'Mi pa dak mel.' --lang zh
python3 -m veka beginner 'Mi pa dak mel.' --lang pt-BR --format json
python3 -m veka beginner 'Mi sen kun.' --lang en
python3 -m veka learner-audit --profile tonal
python3 -m veka learner-audit --profile toneless
make validate
```

## What's included

The progressive course has ten **strictly parsed** canonical examples:
(1) pronoun–predicate–object; (2) SVO; (3) past; (4) negation;
(5) everyday activity; (6) restricted universal quantification;
(7) listening; (8) language vocabulary; (9) exact decimals and units;
(10) transparent compounds. English, simplified Chinese (Mandarin teaching
glosses) and Brazilian Portuguese receive the same Veka sentences but
different **editorial** sentence readings. The localized glossary covers 42
canonical forms/grammar markers, plus decimal digits and special positional
glosses. This is **not** full dictionary localization.

The `beginner` guide provides word-level glosses and an unchanged strict-parse
structure, not sentence translation. Unsupported sentences fail closed.
Uncovered vocabulary in `--lang zh` or `--lang pt-BR` keeps the English
gloss **explicitly marked `(en)`** and includes coverage metadata in JSON.
Unverified international-looking words remain noncanonical reading hints in
`beginner` only. The `lessons` command intentionally hides these draft
forms to teach canonical words. The default English guide is backwards
compatible.

## Pronunciation screening

`learner-audit` emits a JSON inventory of **structural review candidates**
from the current lexicon. This is *not* a likelihood score or evidence of
actual difficulties. Its hypotheses are deliberately narrower than language-
wide stereotypes:

* Mandarin learners: inspect words with `-k`, `-l`, `-s` codas or
  `v`, `z`, `r` onsets; also test pronouns/negation in sentences.
* Brazilian Portuguese learners: inspect certain final codas and regionally
  variable `ti` / `di`; don't assume any single Brazilian accent.
* English learners: inspect rising-tone contrasts, and train the tap `r`
  where needed.

Screening only flags *potential items* for a listening-study design. The audit
does not synthesize speech, test listeners, or justify spelling revisions.

## Evidence required before canonical changes

1. Recruit adults who speak each target language (specify variety, other
   languages, hearing/reading conditions and prior Veka exposure).
2. Randomize matched teaching items. Compare time to criterion, immediate
   and delayed meaning recall, production, comprehension and clarification
   after listening to independently recorded speakers.
3. Pre-register mistakes involving pronouns, negation and quantities as
   potentially consequential. Stratify observations by learner group, word,
   talker and environment.
4. Adopt revisions only when evidence supports an improvement and the
   versioned lexicon/grammar contract can be migrated safely.

Canonical 0.4 roots, 0.3 grammar, and optional 0.5/0.6 structures are unchanged.
Neither tonal nor toneless Veka is being redefined by this pedagogical work.
