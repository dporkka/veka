# Veka at first sight — a beginner reading guide

**Status:** read-only teaching tool for the existing restricted canonical grammar. This is not a new Veka language version, translation engine, or empirically validated comprehension improvement.

## Quick start

From the repository root:

```sh
python3 -m veka beginner 'Mi pa dak mel.'
python3 -m veka beginner 'Mi sen kun.'
python3 -m veka beginner 'Mi sen kun.' --no-cues
python3 -m veka beginner 'Mi sen kun.' --format json
python3 -m veka beginner 'Mi fok mel.' --profile toneless
```

The output keeps the Veka text, annotates each word with an English gloss, and displays the strict parser's grammatical roles:

```text
Veka (tonal): Mi pa dak mel.
Reading aid (English): Mi [I/me] pa [past] dak [send] mel [message].
Parsed structure: subject=mi; predicate=dak; object=mel; tense=past
```

These are word glosses, not a fluent English translation: tense, definiteness, semantic pragmatics and contextual references may need additional interpretation.

## The Interlingua-inspired idea

Interlingua seeks first-sight recognition by choosing international-looking words. Veka's compact vocabulary can be unfamiliar on first exposure. The optional `beginner` command provides *separate* familiar-spelling associations for the **eight unverified draft forms** already in the international research queue.

**No adapted draft is canonical Veka, a verified Interlingua spelling, or a validated globally recognized cognate.** The current examples are influenced heavily by European forms. The tool never replaces canonical words; `--no-cues` suppresses associations completely.

## Six rules to begin reading

1. `mi` = I/me; `ti` = you; `ni` = we/us.
2. Typical clause order is subject – optional tense marker – verb – object. Transitive verbs require objects in strict mode.
3. `pa` = past, `fu` = future, `ne` = negation, `ke` = yes/no question.
4. `al` = every and `kis` = some, with restricted quantified syntax.
5. A post-noun `wen` introduces exact decimal digits; `dis` is the decimal separator and `su` introduces units.
6. `ren-sak` is a transparent *person + knowledgeable* compound; its hyphen is silent, not a separate audible meaning.

## Practice

| Canonical Veka | Word-by-word help | Editorial English reading |
| --- | --- | --- |
| `Mi pa dak mel.` | I – past – send – message | I sent a message |
| `Ti sen kun.` | you – understand – information | You understand information |
| `Mi lin za.` | I – see – computer | I see a computer |
| `Al ren pa gos.` | every – person – past – go | Every person went |
| `Mi pa ne dak mel.` | I – past – not – send – message | I did not send a message |
| `Mi rok sau.` | I – read – book | I read a book |
| `Mi sen nol.` | I – understand – language | I understand a language |
| `Mi sus woi.` | I – listen – music | I listen to music |

The last column is human editorial interpretation, not generated by `beginner`.

## Implementation boundaries and research

Only the strict single-clause core is supported. Invalid or structurally unsupported sentences fail rather than get guessed. Proper names are not translated. The optional toneless lexicon is unchanged; the structured JSON output labels all unverified cues. No root, compound, grammar, parser, or semantic identifier is modified.

Before promoting any international loan, compare first-sight comprehension, retention, speaking and error repair across unrelated language families, with independently checked donor forms and preregistered acceptance criteria. See [international pilot](international_v04.md) and [global-comprehension contract](global_comprehension_v07.md).
