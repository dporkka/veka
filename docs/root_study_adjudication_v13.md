# Veka v1.3 — independent lexical review and blinded first-sight analysis

**Status:** research tooling; no automatic word selection, canonical migration,
human recruitment, human observations, recording, or measured efficacy.

This extends the existing v1.2 root-research and study planner and the
Globasa-informed `root-review`. It does **not** replace the validated
`root-sources` provenance contract, or automatically assert an independent
reviewer has approved any root.

## Independent source-review priorities

The existing `data/root_source_leads_v12.csv` includes 13 pending claims for
C001 **data**, C002 **music**, and C008 **school**. These are research *leads*,
not 13 verified cognates or language-independent etymologies.

Prioritize these external cross-checks before attempting vocabulary adoption:

| Concept / source | Evidence to inspect | Resulting question |
| --- | --- | --- |
| C001, Portuguese `data` | [Priberam Portuguese dictionary](https://dicionario.priberam.org/data), [Infopédia](https://www.infopedia.pt/dicionarios/lingua-portuguesa/data) | Portuguese *data* normally names a calendar **date**, not the information sense of experimental Veka `da-ta`. Keep the false-friend control. |
| C008, Indonesian `sekolah` | [Wiktionary, Indonesian etymology](https://en.wiktionary.org/wiki/sekolah); [historical discussion of Indonesian loans](https://sealang.net/archives/nusa/pdf/nusa-v19-p1-38.pdf) | Loan route Malay → Portuguese `escola`; distinct recipient language families do **not** establish independent word origins. |
| C002, Malay `muzik` | [Wiktionary, Malay](https://en.wiktionary.org/wiki/muzik) | English or Dutch borrowing origin; cross-family spread should not be counted as independent genetic roots. |
| C002, English `music` | [Online Etymology Dictionary](https://www.etymonline.com/word/music) | European words trace ultimately to Greek; verify semantics and sound separately from shared ancestry. |

These are **desk-source corroboration leads**, not fresh attestation approvals.
Published etymologies can disagree, and a source page does not verify who
read it, the correct language section, the date of access, a word's regional
pronunciation, the original root sense, or a proposed Veka pronunciation.
An independent language reviewer must annotate `review_status`,
`semantic_match`, `reviewer`, and `review_note` in a *separate reviewed copy*
of the strict v1.2 source CSV, with provenance and original wording. Do not
overwrite the canonical research template or convert any result to the
`global_evidence_v07.csv` format without a separate reviewed decision.

**Review questions:** Is this the same semantic sense? What regional/register
restrictions apply? Is the apparent cognate inherited, borrowed or convergent?
What is the historical source and intermediate donor? Is it a false friend?
Would an English, Mandarin, Portuguese, Malay or Swahili learner hear the
Veka adaptation as the intended word? Does the adapted spelling resemble
a grammar operator? A superficial lexical family count cannot answer these.

## Actual first-sight response workflow

The existing planner generates participant-only files and a separate
`researcher-key.csv` for each real, consented, pseudonymous language cohort.
**No roster, responses or audio have been generated by this change.**

1. Preregister the target senses, allowed synonymous responses, critical
   misunderstanding classes, candidate/core comparisons, prior-exposure
   exclusion policy, participant/item stratification and a reasonable sample
   size. Enroll and consent participants independently.
2. Generate the existing private study: `root-study-plan`, using a real
   balanced roster. Each participant sees only one form per concept.
3. Collect the filled participant CSV files (same header as generated).
   Concatenate their data rows into one private `responses.csv`, preserving
   the exact seven columns. Complete every response, include response time in
   integer milliseconds, and record `prior_exposure` as `yes`, `no`, or
   `unsure`. The current mode is **written only**.
4. Create a **researcher-only, condition-blind** judge sheet. It omits the
   participant ID, Veka stimulus, background stratum and core/candidate arm,
   but includes the target gloss and the actual free-text answer. Give this
   sheet only to independent judges, never participants.
5. Humans complete `correct` (0/1), `critical_error` (0/1) and
   `judge_id`. Correct answers cannot also be critical errors. Resolve
   disagreements **before** scoring, under a documented adjudication policy.
6. Score the exact filled key, responses, and adjudication CSV. All expected
   trials, participant assignments, forms, conditions and judgments must
   match. A partial, duplicated or altered study fails closed.

```sh
python3 -m veka root-study-judge \
  --key /private/researcher/researcher-key.csv \
  --responses /private/responses.csv \
  --output /private/judge-blank.csv

# After independent human adjudicators have filled the blank sheet:
python3 -m veka root-study-score \
  --key /private/researcher/researcher-key.csv \
  --responses /private/responses.csv \
  --judgments /private/judge-completed.csv
```

Schemas:

- **Key:** `participant_id,trial_id,concept_id,target_gloss,condition,presented_form,background_stratum`
- **Responses:** `participant_id,trial_id,presented_form,response_gloss,response_ms,prior_exposure,presentation_modality`
- **Judgments:** `trial_id,target_gloss,response_gloss,correct,critical_error,judge_id`

The judge-sheet file is created only if absent, with owner-only permissions
where supported. Keep all keys, responses, judge sheets and any consent
records in private folders, not the public repository. The scorer emits
aggregates only, without raw response text or participant identifiers.

The **first-sight** denominator includes only `prior_exposure=no` records;
`yes` and `unsure` remain visible as an excluded count. Reports give
descriptive accuracy, critical errors, and correct responses per observed
minute by form condition, language-background stratum and concept. The
reported time is response time only: there are no validated speech or repair
measurements. A normal exact-head test run uses **synthetic fixtures in
unittest**, never real participants or claimed outcomes.

## Decision and evidence limitations

The command cannot authenticate participants, judge independence, blinding,
trial timing, a preregistration, real-world recruitment, or source provenance.
It rejects malformed and unmatched data, but that is not the same as a valid
scientific experiment. Small sample cells are **not** causal comparisons.
Missing prior-exposure metadata is an error, not silently classified as
first-sight. No confidence intervals, power estimates, p-values or
superiority/no-inferiority claims are produced.

If no human responses exist, **do not generate artificial outcomes** to
advance a vocabulary release. Leave canonical Veka unchanged. Actual spoken
robustness will require separately preregistered natural talker recordings,
noise conditions and blind listening judgments using Veka's listening-study
infrastructure.
