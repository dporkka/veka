# Veka 0.5 — experimental regular morphology and subordinate grammar

**Status:** implemented opt-in reference grammar; no human acoustic/comprehension validation. The 0.4 canonical parser, 1,025 entries, and tonal/toneless profiles are unchanged. This is **not** a complete language grammar.

Veka 0.5 borrows *design principles* from Esperanto's productive morphology and correlative systems, English's predictable conversion, and French's discourse awareness. It does not import irregular grammar, and it deliberately does not implement untested topic/focus particles yet.

## Commands

Run from the repository root (Python 3.10+; standard library only):

```sh
python3 -m unittest discover -s tests -q
python3 -m veka extend "Ren ri wek dak mel yu pa gos."
python3 -m veka extend "Mi lin ren ri ti ton wek yu."
python3 -m veka extend "Mi sen ka ti ton mel yu."
python3 -m veka extend "Hon-ren pa gos."
python3 -m veka extend "Mi gos-vuk ti."
python3 -m veka derive "dak-nes"
python3 -m veka correlative "hon-ren"
python3 -m veka extend "Fok-nes pa gos." --profile toneless
```

The existing `parse` CLI continues to accept only the 0.4 grammar. Use `extend` to opt in. All extension clauses parse **strictly**, prohibiting implicit missing roles and unresolved `sa` pronouns. Content questions set a separate `content_question` field in the AST; yes/no questions retain `ke`.

## Productive event derivation (6 bound suffixes)

The six operators apply to an existing **primitive verb**, not arbitrarily to nouns or compound entries. The derivation is separated with a hyphen and remains transparently compositional. Neither the original dictionary nor the number of headwords changes.

| Suffix | Input | Output | Meaning | Example |
|---|---|---|---|---|
| `-nes` | verb | noun | agent participating in event | `dak-nes` = sender |
| `-sul` | verb | noun | instrument for event | `dak-sul` = sending instrument |
| `-zel` | verb | noun | place of event | `dak-zel` = sending place |
| `-dil` | verb | noun | result of event | `dak-dil` = result of sending |
| `-vuk` | intransitive verb | transitive verb | cause event | `gos-vuk` = cause to go |
| `-kas` | transitive verb | transitive verb | attempt to undo event | `dak-kas` = attempt to undo sending |

These are semantic relations, **not** guaranteed lexical equivalents of English occupational or object nouns. `dak-nes` does not automatically mean professional postal worker. `-kas` does not assert that the event is reversible or that an attempted reversal succeeds. A transitive verb cannot take `-vuk` until the language defines three-place predicates; this fails closed.

The minimum pairwise Hamming distance between suffixes (as three-segment forms) is two. This is a structural screen, **not a perceptual study**.

## Correlatives (4 × 6)

All 24 expressions are generated by `series-domain`. No new arbitrary list of 24 independent words is needed.

| Prefix | Meaning | Example |
|---|---|---|
| `hon-` | interrogative | `hon-ren` = who |
| `hal-` | demonstrative | `hal-ren` = that person |
| `nis-` | indefinite | `nis-ren` = someone |
| `pan-` | universal | `pan-ren` = everyone |

| Domain suffix | Meaning | Example |
|---|---|---|
| `-ren` | person | `hon-ren` = who |
| `-ril` | thing | `hon-ril` = what |
| `-lok` | place | `hon-lok` = which place |
| `-kel` | time | `hon-kel` = when |
| `-wek` | manner | `hon-wek` = how |
| `-gas` | quantity | `hon-gas` = what quantity |

The person/thing/place/time forms can take the syntactic positions the 0.4 parser already supports. Manner and quantity forms **are defined and inspectable but are rejected within sentences** until an adverbial/comparative scope grammar is specified.

An interrogative correlative creates a **content question**, not a yes/no question. It cannot combine with polar `ke`; only one content-question variable is allowed. `pan-` and `nis-` create quantifiers: multiple quantified roles are rejected rather than given an arbitrary binding order. Demonstratives are linguistic deictic forms, not proof that an external referent has been uniquely identified.

## Clause grammar — explicit, bounded

```ebnf
extended_sentence  = atomic | proposition_complement | relative_clause_sentence ;
proposition_complement = subject, "sen", "ka", proposition, "yu" ;
relative_clause_sentence = sentence_with_head,
                           "ri", proposition_with_one_gap, "yu",
                           remaining_sentence ;
gap                 = "wek" ;  (* exactly once, in subject or object position *)
```

Examples:

- `Mi sen ka ti ton mel yu.` — I understand **that you received the message**. The embedded proposition becomes `object_clause`, distinct from a noun object.
- `Ren ri wek dak mel yu pa gos.` — The person **who sent a message** went. The subject-relative clause contains the explicit subject gap `wek`.
- `Mi lin ren ri ti ton wek yu.` — I see the person **whom you received** (grammatically valid regardless of its unusual pragmatic meaning). The object-relative clause has an object gap.
- `Mi gos-vuk ti.` — I cause you to go.
- `Hon-ren pa gos.` — Who went?

`ri` (relative opener), `ka` (propositional complement opener), `wek` (relative gap), and `yu` (mandatory closer, reused from Veka's formal logic) are overt scope words. New grammatical markers cannot collide with existing primitive words in either lexical profile.

The reference implementation supports **one subordinate construction per sentence**, subject/object relative gaps only, and `sen` (*understand*) as the only licensed verb for a propositional object. No gap can appear outside a relative clause. Relative attachment requires an unambiguous canonical bare noun head, not a guessed antecedent. All embedded propositions must be complete, non-imperative and non-interrogative. The parser has a 128-word input limit and rejects recursive embedding.

Important: this scope discipline does **not** imply that the entire meaning is formally modelled, and it does not support nested quantifiers, arbitrary complements, anaphora resolution, counterfactuals, or all natural-language subordination.

## Compatibility, testing, evidence

- Existing `python3 -m veka parse`, `logic`, `profile`, `number`, `international-*`, and study tools remain unchanged apart from a correction to a previous raw `KeyError` for proper-noun objects.
- Existing canonical entries remain exactly as before. Generated expressions are not appended to `data/lexicon.csv`.
- All new constructions are deliberately tested under opt-in `extend`; the original AST remains unchanged for ordinary single clauses.
- Run `python3 -m unittest discover -s tests -q` for regression coverage. Tests establish parser consistency, **not measured human throughput or intelligibility**.
- Future milestones: domain-restricted quantifier semantics, clearer relative-complement licensing, lexical collision screening on growth, and actual recordings / comprehension trials before claiming efficiency gains.
